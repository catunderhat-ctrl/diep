# Diep.io Clone - Android Game

Мобильная игра для Android, являющаяся клоном популярной браузерной игры Diep.io.

## Описание

Это аркадная многопользовательская игра с видом сверху, где вы управляете танком, уничтожаете врагов (геометрические фигуры) и набираете очки для повышения уровня.

### Основные возможности:

- **Twin-Stick Controls**: Два виртуальных джойстика для независимого управления движением и стрельбой
  - Левый джойстик (серый) - движение
  - Правый джойстик (красный) - прицеливание и автоматическая стрельба
- **Враги**: Три типа врагов с разными характеристиками:
  - Квадраты (желтые) - 10 очков, 30 HP
  - Треугольники (красные) - 25 очков, 50 HP
  - Пятиугольники (синие) - 130 очков, 100 HP
- **Система прогресса**: Набирайте очки, повышайте уровень и увеличивайте здоровье
- **Физика и коллизии**: Реалистичная физика движения пуль и объектов
- **Бесконечный игровой мир**: Большая карта 3000x3000 с автоматическим спавном врагов
- **Плавный геймплей**: 60 FPS с оптимизированным рендерингом

## Требования

- Android Studio Arctic Fox (2020.3.1) или выше
- Android SDK 34
- Минимальная версия Android: 7.0 (API 24)
- JDK 17

## Установка и сборка

### Шаг 1: Клонирование репозитория

```bash
git clone <repository-url>
cd diep
```

### Шаг 2: Настройка Gradle Wrapper (если необходимо)

Если у вас еще не установлен Gradle Wrapper JAR:

```bash
# Скачайте gradle-wrapper.jar с официального репозитория
# или установите через Android Studio
```

### Шаг 3: Сборка проекта

#### Через командную строку:

```bash
# Сборка debug версии
./gradlew assembleDebug

# APK файл будет находиться в app/build/outputs/apk/debug/
```

```bash
# Сборка release версии
./gradlew assembleRelease

# APK файл будет находиться в app/build/outputs/apk/release/
```

#### Через Android Studio:

1. Откройте Android Studio
2. Выберите "Open an Existing Project"
3. Выберите папку проекта
4. Подождите, пока Gradle синхронизируется
5. Нажмите "Build" -> "Build Bundle(s) / APK(s)" -> "Build APK(s)"

## Установка на устройство

### Через ADB:

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

### Через Android Studio:

1. Подключите Android-устройство или запустите эмулятор
2. Нажмите кнопку "Run" (зеленый треугольник)

## Управление в игре

Игра использует **twin-stick controls** (два джойстика) - стандарт для мобильных экшн-игр:

### Левый джойстик (серый)
- Расположен в левом нижнем углу
- Управляет **движением танка**
- Танк движется в направлении отклонения джойстика
- Если правый джойстик не используется, танк также поворачивается в направлении движения

### Правый джойстик (красный)
- Расположен в правом нижнем углу
- Управляет **прицеливанием и стрельбой**
- Танк поворачивается в направлении отклонения джойстика
- **Автоматическая стрельба** при использовании джойстика
- Позволяет стрелять в одном направлении, двигаясь в другом

### Дополнительно
- **При Game Over**: Нажмите на экран для перезапуска
- **Совет**: Используйте два пальца одновременно для максимального контроля

## Технические детали

### Архитектура:

- **Язык**: Kotlin
- **Графика**: Android Canvas (2D рендеринг)
- **Игровой цикл**: 60 FPS с фиксированным временным шагом
- **Паттерны**: Объектно-ориентированное программирование, игровой цикл

### Основные классы:

- `MainActivity.kt` - Главная активность приложения
- `GameView.kt` - Основной игровой вид с игровым циклом
- `GameObject.kt` - Базовый класс для всех игровых объектов
- `Tank.kt` - Класс танка игрока
- `Bullet.kt` - Класс пуль
- `Enemy.kt` - Класс врагов (квадраты, треугольники, пятиугольники)
